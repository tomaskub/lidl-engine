# Start with two-stage flyer extraction

The first release uses the existing proof of concept workflow through OpenRouter: source images become descriptions, then descriptions become structured offers, with configurable models. Keeping the description stage preserves a reusable input when structured extraction changes, but the second stage cannot recover facts omitted or misread in that description. Direct structured extraction from images remains an alternative to evaluate if the initial workflow fails the agreed launch checks against original flyer images.
