# Offer Categories 
## Contents 
This document describes main categories for offers posted in lidl flyers, along with the examples of products matching these categories. Categories are based on the product, not on the offer type. 

Tea and coffee sold for brewing belong to pantry items. Ready-to-drink tea and coffee, such as iced tea or a bottled Starbucks coffee drink, belong to non-alcoholic beverages.

An offer spanning product categories can have multiple category labels while remaining one offer. If no category is supported by the source, keep the offer searchable with its category marked unknown.

## Categories list

| Category | Examples | 
| --- | --- |
| bakery | breads, buns, donuts, croissants, pizzerina, calzone, kebab snack |
| alcoholic beverages | beer, wine, apperol | 
| non-alcoholic beverages | juice, iced tea, soda, ready-to-drink coffee |
| fruits | mango, strawberry, banana, mandarine |
| vegetables | potatoes, onion, tomatoe, bell pepper, celery |
| meats | chicken breast, pork shoulder, ground beef, sausage, chorizo |
| seafood | salmon, trout, shrimp | 
| dairy | milk, skyr, yoghurt, eggs, cream, sour cream, kefir, cheddar cheese |
| pantry items | pasta, ketchup, tea for brewing, coffee for brewing, buckwheat, pickles, pesto |
| ready made snacks | cookies, chips, popcorn |
